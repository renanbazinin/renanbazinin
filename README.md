## Forktown: my profile has neighbours

<a href="https://renanbazinin.github.io/forktown/">
  <img alt="Forktown, a pixel-art town with houses around the Lantern Fork, a football pitch and a small concert stage" src="https://renanbazinin.github.io/forktown/og-image.png" width="100%">
</a>

**[Forktown](https://github.com/renanbazinin/forktown)** is a tiny pixel town built one pull request at a time. Every house is a single JSON file sent as a pull request; once CI validates and merges it, the house moves in and hangs a lantern on the Lantern Fork. The residents keep their own routines (walks, football, concerts and films) under a 24-minute day/night cycle and changing seasons.

**Move in from your browser.** All you need is a GitHub account:

1. Open the [live town](https://renanbazinin.github.io/forktown/) and choose <kbd>Find your way in</kbd> → <kbd>Pick an open plot</kbd>.
2. Type your GitHub username and choose <kbd>Create my house file on GitHub</kbd>. GitHub opens a filled-in file for you (if it asks you to fork the repository first, accept).
3. Replace the placeholder story with your own, then choose <kbd>Commit changes</kbd> → <kbd>Propose changes</kbd> → <kbd>Create pull request</kbd>. A first house that changes nothing else merges itself once every check passes.

## Creative Foraging Game

<table>
  <tr>
    <td width="120" align="center">
      <a href="https://renanbazinin.github.io/creative-foraging-game-local/"><img src="https://raw.githubusercontent.com/renanbazinin/creative-foraging-game-local/main/web-version/public/pwa-512.png" alt="Creative Foraging Game icon: ten green blocks joined into one figure" width="100"></a>
    </td>
    <td>
      A browser version of the Creative Foraging Game, a cognitive-science task where players move ten connected blocks on a grid and save the shapes they like to a gallery (<a href="https://doi.org/10.1371/journal.pone.0182133">Hart et al., PLOS ONE 2017</a>). Everything runs on the device with no backend: MediaPipe hand tracking and wrist-color detection estimate which of two players made each move, and each session is saved as JSON and CSV to a local folder you choose.
      <br>
      <sub>React, Vite, MediaPipe (WASM), Vitest, PWA</sub>
      <br><br>
      <a href="https://renanbazinin.github.io/creative-foraging-game-local/">Live demo</a> <sub>(desktop Chrome or Edge)</sub> · <a href="https://github.com/renanbazinin/creative-foraging-game-local">Code</a>
      <br>
      <sub>Earlier build: an <a href="https://github.com/renanbazinin/creative-forging-ai">AI-agent version</a> where Gemini moves blocks and guesses the shape, the demo for a <a href="https://doi.org/10.1145/3765766.3765859">HAI '25 poster</a> I co-authored.</sub>
